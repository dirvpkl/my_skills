# radar CHANGELOG

## 1.0.0 - 2026-11-14

Initial release. The verb-tool technique: decompose a topic into verbs,
search the TOOL of each verb through semantic search (exa-first provider
chain), classify hits (hosted twin / OSS prototype / meta-shelf / venue /
noise), stop per researcher's per-angle rule. Born from a live session
where one tool-class query surfaced an entire competitive class that
object-queries had missed; owner promoted the technique to memory and
ordered the skill. Method only - no session cases (OSS rule).
