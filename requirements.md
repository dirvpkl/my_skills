# requirements — external skills only

Registry for skills that live OUTSIDE this collection — vendored into the
harness's built-in skills root or built into it — with their upstream
sources.
Skills inside my_skills are NOT listed here: the folder layout is the
roster; `AGENTS.md` describes how to work in the repo.

## Vendored into the harness's built-in skills root

- **ponytail** — lazy senior: the minimal-change ladder, lite/full/ultra
  tiers. Upstream: https://github.com/DietrichGebert/ponytail (MIT).
  Loads on coding tasks (harness-side).
- **frontend-design** — visual taste for building/redesigning UI: tokens,
  typography, "not an AI template". Upstream:
  https://github.com/anthropics/skills (MIT).
- **reverse-engineer-anything (REA)** — reverse-engineering binaries,
  managed, Electron/JavaScript, firmware and browser targets via the REA
  MCP; loads on an explicit reverse-engineering task. Upstream:
  https://github.com/morluto/rea.

## Built into the harness (no upstream link)

- skill-creator, plugin-creator — harness scaffolders; live in the harness,
  not here.
