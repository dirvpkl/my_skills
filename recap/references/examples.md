# Examples — recap

**Good:** "what did we do here?" — rebuild from `.workplanx/*/log.md` +
`decision.md` + git log + the memory index, citing the files the story
came from. **Bad:** retelling from chat memory alone — the folder is the
record, the chat is not.

**Good:** hashtag layer (`#slot`, `#decision`) surfaced as the
must-not-forget part of the retelling. **Bad:** filling a `#slot` with a
reconstructed guess — the slot travels as a slot; the owner re-derives.

**Good:** records contradict each other — both are reported with dates.
**Bad:** smoothing a contradiction into one confident story.
