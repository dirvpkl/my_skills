# _graveyard — death records for deleted skills

One folder per dead skill: a `DEAD.md` tombstone (born/died/cause verbatim
from the owner + survival pointers). Corpses are kept ONLY if their content
survives nowhere else; every tombstone lists where the content lives now.
Resurrection rule: recreate a dead skill only if its job outgrows wherever
it survived. Not a skill folder — the catalog loader ignores underscore
entries; this is the anti-reincarnation record.
